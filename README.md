# Tick Tac Toe — App Landing Page

A modern, single-page landing site for the Android app **Tick Tac Toe** by [Puja Sets Nepal](https://play.google.com/store/apps/details?id=com.susmita.game).

🔗 **Live site:** https://tictactoe-landing-three.vercel.app

## Highlights

- 🎮 **Playable tic-tac-toe demo** right in the hero (vs AI & 2-player modes, with score tracking)
- 📥 Official-style **"Get it on Google Play"** download buttons linking to the app
- 🌙 Sleek dark design with glassy nav, animated reveals, and a phone mockup
- 📱 Fully responsive — desktop, tablet, and mobile
- 🔍 SEO-ready: Open Graph tags, JSON-LD `SoftwareApplication` schema, canonical URL
- ⚡ Zero build tools — pure HTML, CSS, and vanilla JS

## Deploy

Every push to `main` auto-deploys to Vercel (GitHub integration is connected).

Manual deploy:

```bash
npx vercel deploy --prod
```

## Structure

```
index.html   # Full landing page markup
styles.css   # Dark modern theme, responsive grid
script.js    # Playable demo game + scroll animations
```
